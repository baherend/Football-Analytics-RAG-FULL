# Official Development Roadmap — FIFA World Cup 2022 RAG System

## Phase 1 — Structured Layer (الأساس الحقيقي)

**Goal:** Build the single source of truth — the real foundation.

**Deliverables:**
- Explicit MatchFacts schema (clearly defined grain)
- Extraction from raw events → persisted structured data
- Unit tests on extraction (small samples, not full data)
- Validation report

**Output Artifact:** `match_facts.json`

**Checkpoint:** Structured data verified against raw StatsBomb events.

---

## Phase 2 — Document Generation (Render Layer)

**Goal:** Generate natural-language RAG documents from the structured layer only.

**Rules:**
- No statistics are computed here.
- No parsing of raw events.
- Pure renderer: structured facts → text.

**Output Artifact:** `documents.json`

**Checkpoint:** Documents validated. Metadata verified. Regression tests pass.

---

## Phase 3 — Structured Query Path (كامل ومستقل)

**Goal:** Build the structured analytics path completely and independently.

**Components:**
- StructuredQuery schema + vocabularies
- Resolver (returns resolved/partial/empty)
- Direct testing: numeric questions answered correctly without any vector store

**Output Artifact:** Structured query engine

**Checkpoint:** Numeric and aggregation questions answerable without vector search.

---

## Phase 4 — Semantic Path (كامل ومستقل)

**Goal:** Build the complete semantic retrieval pipeline completely and independently.

**Components:**
- 02_preprocessing.py
- 03_chunking.py
- 04_representation.py
- 05_embeddings.py
- 06_create_chroma_store.py
- Direct testing: descriptive questions answered correctly without any structured layer

**Output Artifact:** ChromaDB + Retrieval evaluation

**Checkpoint:** Semantic questions answerable using only the vector database.

---

## Phase 5 — Router (Both paths working and independently tested)

**Goal:** Route each user question to the appropriate execution path.

**Possible routes:**
- Semantic only
- Structured only
- Hybrid (both)

**Rules:**
- Router built on clear contracts from Phase 3 and 4
- Edge case testing (ambiguous questions, questions needing both)
- Both paths must be complete and independently tested before router is built

**Output Artifact:** Router module + Routing evaluation

---

## Phase 6 — Generation + Streamlit

**Goal:** Final integration — prompt template that differentiates between complete and honestly partial answers.

**Components:**
- Prompt Builder
- Context assembly
- Honest failure handling
- Final answer generation
- Streamlit UI (search, chat, source display, performance stats)

**Checkpoint:** The system correctly answers semantic, structured, and hybrid questions with honest partial answers when needed.

---

# Engineering Principles

The following principles are mandatory throughout the project:

1. **Single Source of Truth**
2. **Separation of Computation and Rendering**
3. **Separation of Structured and Semantic Retrieval**
4. **Validation before Persistence**
5. **Every phase produces a persistent artifact**
6. **Every phase has an explicit validation checkpoint**
7. **No silent fixes**
8. **Honest failure instead of hallucination**
9. **Production-quality code over quick implementation**
10. **Modular and testable architecture**
